# Node.js CLI Calculator

A simple command-line interface calculator built with Node.js.

## Usage

```bash
node calculator.js <operation> <num1> <num2>
```

### Operations
- `add`: Addition
- `subtract`: Subtraction
- `multiply`: Multiplication
- `divide`: Division

### Example
```bash
node calculator.js add 5 3
# Output: 5 add 3 = 8
```
